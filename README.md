# 个人选股工作台（quant-sentiment-research）

A 股选股工作台。**简简单单就一件事：把选股做好**——统一条件选股引擎：
现成方案一键跑 → 自定义条件任意组合 → 历史回测验证，规则可保存可追溯。
选股结果仅供研究参考，**非买卖指令**。

## 三层用法（conditions.py 统一条件引擎）

- **现成方案**（3 个内置模板，阈值是演示参数不是建议）
  - 低估值：0<PE(TTM)≤20 · 0<PB≤1.5 · 股息率(3年均)≥2.5 · 净利润>0 · 成交额≥3000万，
    按股息率降序取前 30%
  - 质量与成长：ROE≥10 · 近3年报ROE最低≥8 · 营收同比≥10 · 净利同比≥10
    · OCF/净利≥0.8 · 负债率≤60 · 成交额≥3000万，按 ROE 降序取前 30%
  - 趋势突破（纯K线）：站上MA20 · 创60日新高 · 量比>1.5 · 60日收益>0 · 成交额≥0.3亿，
    按 MA20 角度降序取前 20%
- **自定义条件**：27 个指标五大类（基础信息/估值/财务/技术/风险过滤），每个带口径说明；
  AND（全部满足）/ OR（任一满足）/ NOT（排除）/ 区间（between）/ 排名（取前 N%）。
  数据缺失的条件一律「不命中并标注」，绝不当 0 或正常值。
- **策略回测**：仅纯 K 线规则——条件同日成立次日收盘入场、持有 20 日或 -8% 止损、
  持仓期不重叠，逐股回放合并统计（胜率/盈亏比/回撤/夏普，判定阈值同下）。
  含财务/估值条件的规则**拒绝回测**：财务指标历史横截面快照未实现，
  用今天的数据重放历史会引入未来数据泄漏——诚实拒绝而不是给虚高回测。
- **历史验证（功能A）**：选一个历史日期，按**当时可得**的数据（K线截至该日）重新筛选，
  统计入选股持有 20/60/120 交易日的收益率、盈利占比，并对照同期上证基准；
  幸存者偏差、数据缺失、期限不足全部显式提示。同样仅支持纯 K 线组合。
  （完整策略回测——资金分配/调仓/交易成本——为第二阶段。）

规则保存：同名再存版本号 +1，历史版本行保留（改了条件，旧回测仍可追溯）。

## 人工池子（watchlist）

自选名单 + 报价与候选池因子快照；条件选股结果一键「＋自选」。
买前人工清洗清单固定输出（质押/减持/预亏/监管——数据面查不到的雷）。

执行纪律（个股详情页交易计划卡）：30%底仓+30%突破加仓 · -7.5%或破20日线无条件止损
· +15%减半+10日线移动止盈 · 大盘跌破20日线只减不加（sh000001 MA20）。

## 快速开始

```bash
# 后端
pip install -e ".[dev,live]"     # dev=测试，live=akshare 实时行情
pytest -q                        # 全量测试（无 Key 无网全绿）
python scripts/run_api.py        # 起 API，http://127.0.0.1:8610

# 前端（新终端）
cd frontend
npm install                      # 走 npmmirror
npm run dev                      # http://localhost:5610
```

## 数据源指纹

- 财务三表/分红/业绩报表：东财 datacenter 批量整表（push2his 拉黑不受影响）；
  业绩报表带「所处行业」「营收同比」列（候选池行 v4）
- 行情报价/股名：腾讯 qt.gtimg.cn 批量（GBK）；K线：东财主源→腾讯备援+熔断，
  成交额列透传为 amount（回测流动性口径）
- 慢指标（逐股、按天缓存、两段式补数）：PE(TTM) 近5年分位=百度股市通
  （原 PB 指标坏已弃）；扣非增速=东财 F10 主要指标
- 候选池行 v4 按 6h TTL 落 `data/screen_rows_v4_<日期>.json`；K线 parquet 300s TTL

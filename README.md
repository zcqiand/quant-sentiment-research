# 个人选股工作台（quant-sentiment-research）

A 股选股工作台。**简简单单就一件事：把选股做好**——
机器池子用因子交叉从 5000 只里筛出概率占优的少数，人工池子放你真正跟踪的名字，
再用历史回测验证策略、用交易纪律执行。选股结果仅供研究参考，**非买卖指令**。

## 两大主项

- **机器池子**（策略引擎，strategies.py）
  - 模板A 稳健价值：近3年报 ROE 全>15 · 扣非净利增速>20（F10，缺失回退净利润同比）
    · 现金流背书（OCF/净利 3年合计>1 且 FCF 代理=经营+投资现金流 3年合计>0）
    · PB 近5年分位<20 —— 四因子硬交叉，全过才入池
  - 模板B 动量突破：收盘>MA20 · MA20 角度>30° · 创60日新高 · 量比>2 · 成交额≥3000万
  - 策略回测：入场规则逐日回放 → 胜率/盈亏比/最大回撤/夏普；
    判定 = 夏普>1.0 且 胜率盈亏比组合达标（>60%需≥1.5 / 50-60%需≥1.8 / 40-50%需≥2.5），样本<20 笔不过
  - 人工清洗清单：质押>50% / 减持计划 / 预亏预告 / 监管处罚（数据面查不到的雷，买入前必查）
- **人工池子**（watchlist）：自选名单 + 报价与候选池因子快照，机器筛概率、人拿主意

执行纪律（个股详情页的交易计划卡）：30%底仓+30%突破加仓 · -7.5%或破20日线无条件止损
· +15%减半+10日线移动止盈 · 大盘跌破20日线只减不加。

## 快速开始

```bash
# 后端
pip install -e ".[dev,live]"     # dev=测试，live=akshare 实时行情
pytest -q                        # 全量测试（无 Key 无网全绿）
python scripts/run_api.py        # 起 API，http://127.0.0.1:8610

# 前端（新终端）
cd frontend
npm install                      # 走 npmmirror
npm run dev                      # http://localhost:5610
```

## 数据源指纹

- 财务三表/分红：东财 datacenter 批量整表（push2his 拉黑不受影响）
- 行情报价/股名：腾讯 qt.gtimg.cn 批量（GBK）；K线：东财主源→腾讯备援+熔断
- 估值分位（PE/PB 近5年）：百度股市通；扣非增速：东财 F10 主要指标
- 候选池行 v3 按 6h TTL 落 `data/screen_rows_v3_<日期>.json`；PB分位/扣非增速按天缓存
